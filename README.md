# Node.js + React + Vite GSB 项目集合

本目录包含三个从零生成的基础项目，均采用 React + Vite + TypeScript 前端，以及 Node.js + TypeScript 后端：

- `workflow-engine/`：可配置自动化工作流引擎
- `feature-flags/`：Feature Flag 与灰度发布服务
- `api-mock/`：API 请求录制与 Mock 回放平台

三个项目均以基础功能为主，采用内存存储或轻量实现，保留后续扩展数据库、鉴权、队列和持久化的空间。每个子项目都有独立的 README 和 package.json。
